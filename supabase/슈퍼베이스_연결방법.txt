경성야록 · 슈퍼베이스(Supabase) 진짜 연결하기
발표 자료 「데이터 구조」 장의 내용을 실제 데이터베이스로 만드는 순서

지금 상태: 사이트에 회원 화면(독자 입장 · 독자의 방 · 錢 · 상점)은 다 있음.
          설정이 비어 있어서 「시연 모드」(그 컴퓨터 안에서만 저장)로 돌아가는 중.
아래 순서를 마치면 진짜 회원가입 · 로그인 · 독자의 방 저장이 됨 (컴퓨터판 · 폰판 같이).

2. 「New project」 누르기
   - Name: gyeongseong-yarok
   - Database Password: 아무거나 길게 (어디 적어 두기)
   - Region: Northeast Asia (Seoul)
3. 「Create new project」 → 1~2분 기다리기

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
2단계 · 데이터베이스 만들기 (복사 · 붙여넣기 한 번)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 왼쪽 메뉴 「SQL Editor」 → 「New query」
2. 이 폴더의 「경성야록_데이터베이스.sql」 파일을 메모장으로 열어 전체 복사 (Ctrl+A → Ctrl+C)
3. SQL Editor 빈칸에 붙여 넣기 (Ctrl+V) → 오른쪽 아래 「Run」
4. 아래에 「Success」가 나오면 끝
   → 왼쪽 「Table Editor」에 profiles · shop_items · owned_items · room_layout 네 개가 보임
   (발표 자료 데이터 구조와 같음. 서버 기능 buy_item · claim_read · demo_charge 도 같이 만들어짐)

3단계 · 로그인 설정 (발표용으로 메일 확인 끄기)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 왼쪽 「Authentication」 → 「Sign In / Providers」 (또는 Providers)
   - Email 이 켜져 있는지 확인
   - 「Confirm email」 끄기 → Save  (끄면 가입하자마자 바로 입장됨. 켜 두면 메일 확인을 눌러야 입장)
2. 「Authentication」 → 「URL Configuration」
   - Site URL:  https://ejdms499-wq.github.io/gyeongseong-yarok_v/
   - Redirect URLs 에 「Add URL」로 아래 하나 추가
     https://ejdms499-wq.github.io/gyeongseong-yarok_v/**
   - Save

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
4단계 · 사이트에 열쇠 넣기
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 슈퍼베이스 왼쪽 아래 톱니 「Project Settings」 → 「API」 (또는 Data API / API Keys)
   - Project URL  (https://xxxx.supabase.co 모양) 복사
   - anon public 열쇠 (eyJ... 로 시작하는 긴 글자) 복사
   ※ service_role 열쇠는 절대 넣지 말 것 (anon 은 공개해도 되는 열쇠)
2. 사이트 폴더에서 m 폴더 → yk-config.js 를 메모장으로 열기
3. 아래 두 줄의 '' 사이에 붙여 넣기

     SUPABASE_URL: 'https://xxxx.supabase.co',
     SUPABASE_ANON_KEY: 'eyJ......',

4. 카카오 · 네이버 로그인은 슈퍼베이스에 따로 설정해야 열림.
   설정 안 할 거면 같은 파일에서 두 줄을 false 로 바꿔 단추를 숨기기

     KAKAO: false,
     NAVER: false

5. 저장 → 깃허브 데스크톱에서 Commit → Push origin
