경성야록 · 독자 호외 「카카오톡으로 보내기」 진짜로 켜는 법
────────────────────────────────────────
지금 상태
  · 휴대폰 / 윈도우 크롬·엣지 : 「카카오톡으로 보내기」를 누르면 기기의 공유 창이 열림 → 카카오톡 고르면 호외 그림이 감
  · 공유 창이 없는 브라우저 : 그림을 복사해 둠 (마지막 수단)

버튼 하나로 카톡 「친구 고르기」 창이 바로 뜨게 하려면 (팀에서 한 번만)
  1) 사이트를 인터넷 주소에 올리기 (예: GitHub Pages, Netlify — 무료)
  2) developers.kakao.com 에 로그인 → 내 애플리케이션 → 애플리케이션 추가
  3) [앱 설정 → 플랫폼 → Web] 에 1)의 인터넷 주소 등록
  4) [앱 키] 의 「JavaScript 키」 복사
  5) 사이트 폴더의 yk-kakao.js 를 메모장으로 열어
       window.YK_KAKAO_KEY = '';   ← 따옴표 안에 붙여 넣고 저장
  → 그 뒤로는 누르면 카톡 창이 뜨고, 호외 그림 + 「호외 펼쳐 보기」 버튼이 카드로 감.
    받은 사람이 버튼을 누르면 그 호외가 그대로 펼쳐짐. (상점 엽서도 같은 열쇠로 같이 켜짐)
