경성야록 — 메인 페이지(신문 지면 화면) 서버 전달용
==================================================

1. 첫 화면으로 열어야 하는 파일
--------------------------------------------------
  index.html

  · 처음 열면 오프닝(마이크로필름 장면, 약 12초)이 나온 뒤 메인 신문 지면이 뜹니다.
  · 오프닝 없이 메인을 바로 보려면 주소 끝에 #main 을 붙이세요.
      예) https://도메인/경로/index.html#main
  · 화면 이동은 주소 끝의 # 으로만 합니다 (#main, #a/사건id, #list/면id, #appendix).
    그래서 서버에 따로 주소 연결(rewrite) 설정을 할 필요가 없습니다.


2. 폴더 구조 (이대로 유지해야 합니다)
--------------------------------------------------
  main-for-server/
  ├─ index.html        첫 화면. 뼈대만 있고 실제 지면은 app.js가 그림
  ├─ styles.css        디자인 전부
  ├─ data.js           글 · 사진 경로 · 칸 구성 데이터  (app.js보다 먼저 불러옴)
  ├─ app.js            동작 전부
  ├─ README.txt        이 파일
  ├─ images/           메인 대표 사진 · 인물 사진 (이미 톤 보정된 사진)
  │   ├─ social-1933-05-17.jpg      사회면 대표 사진
  │   ├─ fraud-1940-03-14.jpg       사기면 대표 사진
  │   ├─ person-hyeon-jingeon.jpg   인물면 · 현진건
  │   ├─ person-lee-gilyong.jpg     인물면 · 이길용
  │   ├─ person-yun-simdeok.jpg     인물면 · 윤심덕
  │   └─ person-jang-jinhong.jpg    인물면 · 장진홍
  └─ assets/
      ├─ illust/
      │   ├─ jukcheom_map_ahyeon.jpg   사회면 작은 카드 (당시 지도)
      │   ├─ dokkaebi.jpg              사기면 작은 카드
      │   └─ sagi_pen.png              암전 바꿔치기용 (짝 파일 sagi_pen_alt.png가 아직 없어 지금은 화면에 안 나옴)
      ├─ scans/
      │   ├─ _body/body-a~d.jpg        메인 종이 뒷면 비침 무늬 (styles.css · app.js)
      │   ├─ sohn-gijeong/05.jpg       문화예술면 대표 (사진 일부를 잘라 보여줌)
      │   ├─ sohn-gijeong/07.jpg       문화예술면 작은 카드 (일부)
      │   ├─ poison-12days/02.jpg      사기면 작은 카드 '당시 광고' (일부)
      │   └─ 그 밖의 스캔들            오프닝 필름 칸에 흐르는 당시 지면 (마지막 칸 = baekbaekgyo/13.jpg)
      └─ fonts/
          ├─ jaegeonsa.woff2, .ttf     재건사 붓글씨체 — 현재 코드에서 쓰지 않음 (요청에 따라 보관용으로 포함)

  ※ 모든 경로는 index.html 기준 상대 경로입니다 (예: images/..., assets/...).
    폴더 이름이나 위치를 바꾸면 사진이 안 보입니다. 이 폴더를 통째로 올려 주세요.
  ※ 서버가 대소문자를 구분할 수 있으니 파일 이름을 바꾸지 마세요.


3. 필요한 것
--------------------------------------------------
  · 별도 설치 없음. 빌드 과정 없음. 데이터베이스 없음.
  · 정적 파일(HTML · CSS · JS · 이미지)만 올려 주면 되는 웹서버면 됩니다.
  · 외부에서 불러오는 것은 구글 폰트 하나뿐입니다 (index.html의 link 태그)
      - Noto Serif KR (400 · 700 · 900) : 본문 · 제목 · 한자
      - Song Myung : 대표 사진 옆 어두운 판의 큰 제목 · 부제
    인터넷이 막힌 환경에서는 컴퓨터에 있는 명조체로 대신 보입니다 (화면은 깨지지 않음).
  · fonts/fonts.css 파일은 이 프로젝트에 없습니다. 폰트는 위 구글 폰트로만 불러옵니다.
  · index.html 파일을 더블클릭으로 직접 열어도 대부분 보이지만,
    정확한 확인은 웹서버를 통해 열어 주세요. (내 컴퓨터에서 확인할 때 예: 이 폴더에서
    python -m http.server 8000 실행 → 브라우저로 http://localhost:8000/ 접속)


4. 알아 두실 점
--------------------------------------------------
  · 이 묶음은 '메인 페이지'에서 쓰는 파일만 담았습니다.
    메인의 칸 · 카드 · 인물을 누르면 상세 · 목록 · 부록 화면으로 넘어가는데,
    그 화면들의 사진(원본 프로젝트의 assets/ 나머지 파일)은 들어 있지 않아 빈 칸으로 보일 수 있습니다.
    전체 사이트가 필요하면 원본 프로젝트의 assets/ 폴더 전체를 같은 위치에 더 올리면 됩니다.
  · 브라우저 개발자 도구(콘솔)에 아래 파일들의 404(없음)가 보이는 것은 정상입니다.
    원본 프로젝트에도 아직 없는 파일이고, 없으면 코드가 알아서 건너뜁니다.
      assets/sound/type.mp3, enter.mp3, rewind.mp3, clunk.mp3, thud.mp3, burn.mp3  (없으면 브라우저 합성음 사용)
      assets/illust/shahoe_photo.png, shahoe_photo_alt.png, sagi_pen_alt.png       (암전 바꿔치기용, 준비 중)
  · 코드 내용은 원본과 같고, 한국어 주석만 추가했습니다.
    각 파일 맨 위에 그 파일의 역할 · 연결 관계 · 서버에서 지킬 점이 적혀 있습니다.
  · 오프닝을 한 번 본 브라우저는 다음부터 오프닝 중간(멈춤 장면)부터 시작합니다.
    이 기록은 그 사람 브라우저(localStorage 'yarok-film-seen')에만 저장되고 서버에는 저장되지 않습니다.
