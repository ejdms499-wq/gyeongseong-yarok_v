# 경성야록 배포 및 업로드 안내서

이 문서는 완성된 **경성야록** 웹사이트를 GitHub에 올리고 인터넷에 공개(GitHub Pages)하는 방법을 일반인의 눈높이에 맞추어 순서대로 설명합니다.

---

## ⚠️ 업로드 전 꼭 읽어둘 주의사항

> [!CAUTION]
> **웹 브라우저의 GitHub 화면에 파일을 마우스로 끌어다 올리는 방식(Drag & Drop)은 절대 쓰지 마세요.**  
> 웹 업로드는 한 번에 최대 100개 파일까지만 처리되므로, 2,000개가 넘는 경성야록 프로젝트 파일이 누락되어 사이트가 정상 동작하지 않습니다.

> [!IMPORTANT]
> **`.git` 폴더는 절대 덮어쓰거나 지우지 마세요.**  
> 압축 파일 안에는 `.git` 폴더가 들어있지 않습니다. GitHub Desktop이 만들어 둔 숨김 폴더인 `.git`을 그대로 유지해야 안전하게 업로드됩니다.

---

## 🚀 6단계 배포 가이드

### 1단계: 받은 압축 파일 풀기
1. 전달받은 **`경성야록_업로드_20261020.zip`** 파일의 압축을 풉니다.
2. 압축을 푼 폴더 안에 `opening.html`, `index.html`, `cases/`, `exhibits/`, `sikjasil/` 등의 폴더와 파일들이 잘 보이는지 확인합니다.

---

### 2단계: GitHub Desktop 설치 및 저장소 가져오기 (Clone)
1. [GitHub Desktop 공식 사이트](https://desktop.github.com/)에서 프로그램을 내려받아 설치하고 로그인합니다.
2. GitHub Desktop 상단 메뉴에서 **File → Clone Repository**를 누릅니다.
3. **URL** 탭을 선택하고 다음 저장소 주소를 입력합니다:
   - 저장소 주소: `https://github.com/ejdms499-wq/gyeongseong-yarok_v`
4. **Local path**(내 컴퓨터 저장 위치)를 확인한 뒤 **[Clone]** 버튼을 누릅니다.
5. 저장소 복제가 완료되면 내 컴퓨터에 해당 이름의 빈 폴더(또는 이전 버전 폴더)가 생깁니다.
6. 저장소 주인(ejdms499-wq) 계정이거나 주인이 협업자(Collaborator)로 초대한 계정으로 로그인해야 올릴 수 있습니다. Push가 거부되면 주인에게 초대를 요청하세요.

---

### 3단계: 압축 푼 파일을 저장소 폴더에 복사하기
1. **저장소 폴더에 예전 파일이 있다면, 숨김 폴더 `.git`만 남기고 나머지 파일·폴더를 모두 지운 뒤 붙여 넣으세요.** 덮어쓰기만 하면 이번에 정리한 옛 파일이 그대로 남습니다.
2. **1단계에서 압축을 푼 폴더 안의 모든 파일과 폴더**를 전체 선택(`Ctrl + A`)하여 복사(`Ctrl + C`)합니다.
   - 맥에서는 Finder에서 `Cmd + Shift + .` 을 눌러 숨긴 파일(`.nojekyll` 등)이 보이게 한 뒤 전체 선택하세요.
3. **2단계에서 Clone한 저장소 폴더**로 이동하여 붙여넣기(`Ctrl + V`)합니다.

---

### 4단계: GitHub Desktop에서 커밋(Commit) 및 푸시(Push)
1. **GitHub Desktop** 프로그램 창으로 돌아옵니다.
2. 화면 왼쪽에 변경·정리된 파일 목록이 자동으로 나타납니다.
3. 화면 왼쪽 아래 **Summary (required)** 입력 칸에 다음과 같이 한 줄을 적습니다:
   ```text
   경성야록 최신 버전 업로드
   ```
4. 파란색 **[Commit to main]** (또는 Commit to master) 버튼을 누릅니다.
5. 커밋이 완료된 후 상단 메뉴의 **[Push origin]** 버튼을 누르면 파일이 GitHub로 업로드됩니다. (파일 크기에 따라 1~3분 정도 걸릴 수 있습니다)

---

### 5단계: GitHub Pages 공개 설정 확인
1. 웹 브라우저에서 저장소 설정 페이지로 이동합니다:
   - 주소: `https://github.com/ejdms499-wq/gyeongseong-yarok_v/settings/pages`
2. **Build and deployment** 섹션의 설정을 확인합니다:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` (또는 `master`), 폴더는 **`/(root)`** 선택
3. **[Save]** 버튼을 누릅니다. (이미 설정되어 있다면 그대로 두셔도 됩니다)

---

### 6단계: 공개 웹사이트 접속 확인
1. 푸시 후 약 1~3분이 지나면 GitHub 서버에서 자동으로 배포가 완료됩니다.
2. 아래 공개 주소로 접속하여 사이트가 열리는지 확인합니다:
   - 🌐 **공개 주소**: **https://ejdms499-wq.github.io/gyeongseong-yarok_v/opening.html**
3. 화면이 예전 모습으로 보이거나 변경 사항이 반영되지 않은 것처럼 느껴지면, 키보드의 **`Ctrl + Shift + R`** (강력 새로고침)을 눌러 캐시를 비우고 다시 확인합니다.
